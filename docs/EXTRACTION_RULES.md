# Extraction rules

## File discovery (E0)

Paths are enumerated (symlinks not followed, `.git` skipped), sorted ordinally and filtered in this order; every decision is
reason-coded in `discovery.jsonl`:

1. `discovery.include` (pilot: `src/**/*.cs`, `tests/**/*.cs`) — non-matching paths are not recorded.
2. `excluded_path` (`**/obj/**`, `**/bin/**`, …), `too_large`, `vendored_path`, `generated_path` (`*.g.cs`, `*.Designer.cs`,
   `**/Migrations/**`, `*ModelSnapshot.cs`, …).
3. Decoding: `utf16_encoding`, `invalid_utf8`, `binary_nul`; `empty`.
4. `generated_marker`: `<auto-generated`, "This code was generated by a tool", `[GeneratedCode(` in the first 4000 chars —
   tool-generated code is recognized by content, not only by name.
5. `long_lines` (minified-like), `license_not_allowed` (repository license unknown/not allowlisted and `allow_unknown=false`),
   `secret_detected` (configurable regexes), `exact_duplicate` (sha256 already seen; `duplicate_of` names the first path).

Tests are **not** excluded; `is_test` (via `test_patterns`) lets reports measure their share separately. License is detected
from the root LICENSE text (MIT / Apache-2.0 signatures); a declared license that conflicts with the file blocks the repo.

## Caret candidates (syntax only)

Generated from Roslyn tokens on each non-blank physical line (parsed with `LanguageVersion.Preview`, no preprocessor
symbols defined, so `#if` branches that are inactive by default are counted as `inactive_preprocessor_code`):

| Kind | Positions |
|---|---|
| `line_start` | after indentation; subkind = statement/member kind (`local_declaration`, `invocation`, `return`, `attribute`, `method_declaration`, `continuation`, `brace`, …). This is the "empty line" case: the editor has only the indentation. |
| `identifier_partial` | 1..`identifier_prefix_max` chars into an identifier, plus camel-hump boundaries; never inside a surrogate pair |
| `member_access` | after `.` (member access), `?.`, qualified names, `->` |
| `argument_list` | after `(` / `[` of argument lists, after `,` (+space), parameter lists |
| `after_keyword` | after `return await new throw yield is as case when in var else nameof typeof` (+space) |
| `after_operator` | after `=` (assignment/initializer), `??`, `??=`, `+=`, `==`, `&&`, `||`, `?:`, initializer `{` |
| `control_flow` | after `(` of `if while foreach for switch catch using lock when do` |
| `lambda_body` | after `=>` (lambda, expression body, switch arm) |
| `linq` | `member_access`/`argument_list`/`lambda_body` carets inside a query expression or a LINQ method chain (subkind keeps the original kind) |
| `log_message` | template literal of `ILogger.Log*` calls (`template_start` before the quote, `template_body` after it) and `[LoggerMessage(Message = …)]` |
| `token_boundary` | end of any token (low weight) |

One candidate per offset (highest-priority kind wins). Tags: `linq`, `lambda`, `await`, `pattern`, `switch_expression`,
`initializer`, `collection_expression`, `attribute`, `exception`, `using_directive`, `record`, `log_call`, `test_code`.

## Negative strata (counted, sampled into `exclusions.jsonl`, never silently dropped)

Line level: `comment`, `doc_comment`, `preprocessor_directive`, `inactive_preprocessor_code`, `inside_raw_string`,
`inside_multiline_string`, `inside_interpolated_string`, `too_long`. Caret level: `in_string`, `in_interpolated_string`,
`in_raw_string`, `in_char_literal`, `in_comment`, `caret_inside_literal`, `caret_inside_trivia`, `raw_multiline_string`,
`multiline_string`, `splits_surrogate_pair`, `empty_target`, `target_too_long`, `secret_detected`.

## Sampling

For each eligible candidate `u = sha256(seed ␟ "caret" ␟ source_sha256 ␟ offset)` → [0,1). Accepted if `u < weight[kind]`
(× `trivial_target_keep_probability` for trivial targets). Then per line keep the `max_samples_per_line` lowest `u/weight`, then
per file the `max_samples_per_file` lowest; output in source order. Selection depends only on (seed, file content, offset,
config) — not on worker count or file order. Dataset-level: later samples whose (trimmed line, caret column) already occurred
are dropped (`samples.dropped_duplicate`), which removes boilerplate such as repeated `using` lines.

Records (context strings, flags, tags, byte offsets) are materialized only for survivors; extraction is linear in file size
(see the large-file test).

## Semantic snapshot

* `editor_snapshot`: `text[..caret] + text[target_end..]` — the target suffix is removed, the rest of the file stays.
* `strict_prefix`: `text[..caret]` + one `}` per unclosed `{` of the prefix (computed from the prefix only, recorded in
  `synthetic_suffix`), so the caret sits inside its member instead of on the end-of-file token.

Rules that keep facts honest:

* Locals declared at/after the caret, or in the declarator being typed (`var order = await repo.▮`), are excluded.
* Symbols declared after the caret in the snapshot are kept only if the original document declares the same kind/name at
  the shifted location; otherwise they are error-recovery artifacts (e.g. a method body re-parsed as fields once its header
  line was removed) and counted in `dropped_recovery_artifacts`. The original is used only to drop, never to add facts.
* Static context hides instance members and primary-constructor parameters.
* Leakage audit per record; `validate` fails on any violation.

## Semantic engines (`semantic.engine`: `auto` | `fork`)

`auto` picks, per caret, the cheapest engine that still analyzes the target-free snapshot (`analysis_engine` in each record):

| Engine | When | How |
|---|---|---|
| `statement_scope` | caret at a statement start (or inside its first token) in a member body | scope at the statement start in the original model (identical preceding text; method binding cached per file); locals declared by the edited statement are excluded by position; no expression facts |
| `speculative` | caret inside a method/accessor body, field/property initializer, `=>` property, attribute, top-level statement | incremental re-parse of the snapshot (`SourceText.WithChanges` + `WithChangedText`), then `TryGetSpeculativeSemanticModel[ForMethodBody]` of the edited node against the original compilation |
| `speculative_scope` | member headers, `using` directives, between members, namespace level | lookups at an anchor of the same scope before the caret (type `{`, namespace start); snapshot expressions bound with `GetSpeculativeSymbolInfo` |
| `fork` | everything else (e.g. caret at the start of a top-level statement) and as a retry when a speculative model throws (`fork_after_speculative_error`) | whole-document fork: new compilation |

Rules shared by all engines: symbols whose **declaration header** overlaps the edited span are dropped (their name/signature is
partly hidden); a declaration whose identifier contains the caret is "being typed" and is not a fact (`out var su|bscriptions`);
strict_prefix drops declarations of this file at/after the caret. Member lists and their display strings are cached per file at
the canonical type anchor (deterministic, independent of processing order). Compared with the fork reference on 970 eShop
samples, 90% have identical facts; the differences were reviewed: dropped half-typed member headers (more conservative),
namespace instead of global namespace as enclosing symbol, own members that fork's artifact filter lost (more correct).
