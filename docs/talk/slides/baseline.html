Строка угадана целиком — у готовой C#-модели плагина 50M. Первое правило: сравнивать только на одинаковом, честно изолированном наборе.

4 · cs-nn-50m-e3-lr2e3 · «строка целиком» = остаток строки совпал с точностью до хвостовых пробелов

Отправная точка — модели, которые уже стояли в плагине. Для C# в отчёте движка была цифра 51,6 процента угаданных строк. Мы собрали собственный чистый набор — 12 тысяч позиций из репозиториев, которых не видела ни одна модель, — и та же самая модель на нём даёт 32,7. Дело не в том, что модель плохая: просто тесты разные. Тест движка брал позиции из той же генеральной совокупности кода, а наш — из свежих маленьких репозиториев, где код разнообразнее. Отсюда первое правило всей работы: никаких сравнений «наша цифра против их цифры», только одинаковый набор и парный бутстрап.
