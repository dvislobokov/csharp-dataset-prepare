public async Task StopAsync()
{
    await _client.StopAsync();
}

Курсор — после точки. Серым — остаток строки, Tab принимает. Показываем, только если модель уверена.

CPU ноутбука

строка ≤ 150 мс, холодный файл ≤ 1 с

Без внешних рантаймов

свой движок: Kotlin + нативные int8-ядра, формат .cml

Маленькая модель

50 МБ в плагине, 50–100 млн параметров

2 · плагины idea-dotnet-support (C#) и idea-golang-support (Go)

Задача простая на словах: пользователь пишет код, а мы предлагаем остаток текущей строки серым текстом. Tab — принять. Но ограничения жёсткие. Всё работает на процессоре ноутбука пользователя, бюджет — 150 миллисекунд на строку и секунда на первый «холодный» файл. Никаких внешних рантаймов: у плагина свой движок на Kotlin с нативными int8-ядрами и свой формат модели. И модель маленькая — около 50 мегабайт в плагине. То есть никакой большой LLM: всё качество нужно выжать из 50 миллионов параметров, и выжимать его будем данными и обучением.
